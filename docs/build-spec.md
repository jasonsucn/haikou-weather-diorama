## 3. 资产规格（Coder A）

### 3.1 场景坐标（世界单位，Y-up 导出；Blender 里 Z-up）

- 底座：半径 112，托盘高 ~7，顶面 z≈1.1；海面半径 108，海面 z≈1.1；木纹外圈 + 铜牌。
- 主岛：有机 blob，约 170×125，中心 (8,-2)，顶面 z≈2.4；沙滩环 + 浅水泡沫环。
- 海甸岛：西北海上独立小岛，中心约 (-68,50)，约 55×32；灯塔 + 渔村 + 椰林；与主岛之间是可见水道（宽 15–25），**不要用 V2 的陆地切口**。
- 世纪大桥：跨水道，从主岛 (-35,25) 到海甸岛 (-58,42) 附近，跨度 30–40；A/H 形双塔、斜拉索扇形、桥面微拱、栏杆、双向车道；桥面顶 z≈13。
- 骑楼老街：西岸，沿南北向排 8 个开间，面朝西（-X），进深 12，高 12–15；连续拱廊、柱、女儿墙、山花、招牌、遮阳棚、二三层窗。
- 钟楼：老街南端 (-45,-32) 附近，总高约 30；红砖基座 + 白塔身 + 四面钟 + 攒尖顶 + 塔尖。
- 云洞图书馆：老街北侧水岸 (-50,18) 附近，白色有机壳体约 14×10×8，3 个圆形洞口，临水。
- 万绿园：东南 (10,-38) 附近，约 45×30；草坪、湖面、步道、椰林、少量长椅/凉亭。
- 火山口：东侧 (55,-30) 附近，锥形山体底径约 34、高 14、火山口凹陷、观景台、绿坡。
- CBD：中部偏北 (0..40, 5..25)，4–5 栋圆角塔楼，高 30–50，玻璃蓝/白。
- 老城肌理：老街与 CBD 之间 40+ 个低层街块（进深 8–12，高 5–9），屋顶色分区；这是**填充空旷感的关键**。
- 东岸渔村：10 栋左右小房子 + 小路。
- 码头：西南海面 3 组栈桥 + 9 艘渔船（可动画）+ 防波堤；外海 3 艘帆船。
- 椰树/乔木 60+；云 3 组；飞鸟留给 App 生成。

> 密度硬指标：陆地占底座 ≥45%（V1 版面下尽量靠 45–50%）；岛内可感知内容覆盖 ≥65%；任何直径 >25 的空白区必须被街块/树/水景/地形填上；海面必须有码头/船/防波堤。

### 3.2 动画锚点命名（App 依赖，必须遵守）

| 前缀/名称 | 数量 | 用途 |
| --- | --- | --- |
| `Sea` / `Foam` | 1 / 1 | 海面替换 shader、泡沫呼吸 |
| `Car_01` … `Car_06` | 6 | 车流沿桥移动（App 驱动） |
| `Boat_01` … `Boat_09` | 9 | 渔船起伏 + 巡航 + 尾迹 |
| `Cloud_1` … `Cloud_3` | 3 | 漂移 |
| `Palm_01` … | ≥12 | 摆动（App 按 y 轴旋转/顶点） |
| `ClockTower` / `Bridge_Tower_L/R` / `Library` / `Park` / `Volcano` / `Haidian` | 1 each | 点击拾取、标签、镜头推近 |
| `Arcade_01` … `Arcade_08` | 8 | 地标组（可合并拾取） |

- 每个可动件原点放在合理位置（车在底盘中心、船在水线中心、云在中心）。

- 材质 ≤ 24；三角面 ≤ 150k；GLB ≤ 8 MB。

## 4. App 规格（Coder B）

### 4.1 架构

```
server.mjs        静态服务 + QWeather 代理 + 内存/磁盘缓存
app/index.html    importmap: three -> /vendor/three.module.min.js, three/addons/ -> /vendor/addons/
app/styles.css    HUD / 面板 / 响应式
app/src/main.js   启动、渲染循环、交互
app/src/weather.js 数据获取、归一化、时间轴数据
app/src/city.js   GLB 加载、命名锚点、车流/渔船/飞鸟
app/src/effects.js 雨/雪/雾/闪电/云/海面 shader
app/src/ui.js     顶栏、天气卡、时间轴、地标按钮、弹层
app/src/sound.js  WebAudio 程序化音效（无外部音频文件）
```

- 端口 **8787**；`start.cmd` 内容：`node server.mjs` + 自动打开浏览器（可选）。
- 无 npm 依赖；只用 Node 内置模块 + 本地 vendor。
- 浏览器桌面优先（Chrome/Edge），移动端基础可用（DPR≤2、粒子降档）。

### 4.2 QWeather 代理

`.env.qweather` 已存在：
```
QW_API_HOST=xxxxxxxx.qweatherapi.com
QW_API_KEY=...
```
服务端读取，禁止下发前端。代理接口：

| 路由 | 说明 | 缓存 |
| --- | --- | --- |
| `GET /api/weather/summary` | 聚合 current + 24h + 7d + air + alerts + indices + astro | 10 min |
| `GET /api/weather/hourly?hours=24` | 逐小时 | 30 min |
| `GET /api/weather/daily?days=7` | 每日 | 60 min |
| `GET /api/health` | 状态/是否命中缓存 | — |

坐标 `20.04,110.34`。真实接口（已验证）：

```
/weather/v1/current/{lat}/{lon}?localTime=true&lang=zh
/weather/v1/hourly/{lat}/{lon}?hours=240&localTime=true&lang=zh   -> hours[]
/weather/v1/daily/{lat}/{lon}?days=10&localTime=true&lang=zh      -> days[]
/airquality/v1/current/{lat}/{lon}?lang=zh
/weatheralert/v1/current/{lat}/{lon}?lang=zh                      -> alerts[]
/v7/indices/1d?type=1,2,3,5,8&location=110.34,20.04&lang=zh
```
请求头 `X-QW-Api-Key`。失败降级：用 `data/qweather/snapshot-haikou.json` + 本地模拟曲线，UI 标注“缓存/演示”。

### 4.3 场景

- 加载 `assets/models/haikou_v1.glb`；缺失时显示简单占位城（不要白屏），并在 HUD 标注“资产加载中”。
- 相机：PerspectiveCamera 45°，初始位置约 (200,-260,150)，lookAt (0,0,10)（按 GLB 实际范围微调），OrbitControls 阻尼、自动旋转可开关、双击复位。
- 光照：DirectionalLight（按日出/日落计算方位）+ HemisphereLight + 环境光；阴影 2048；夜间切换月光 + 城市点光。
- 天空：Shader 渐变（昼/昏/夜），太阳/月亮圆盘；雾按能见度。
- 海面：用 GLB 的 `Sea` 替换为自定义 ShaderMaterial（顶点波浪 + 高光 + 菲涅尔），或叠加一层；泡沫呼吸用 `Foam` 缩放/透明度。
- 后处理：轻微 Bloom + vignette；不要重到掉帧。

### 4.4 动画（优先级）

**必须惊艳的三项：**

1. **车流**：`Car_01..06` 沿桥面双向循环移动，车头灯夜间发光（emissive + 小光晕），过桥有轻微起伏；夜间车灯拖影。
2. **渔船**：`Boat_01..09` 随波起伏（sin 相位错开）+ 缓慢巡航/转向 + 船尾 V 形尾迹（半透明面片）+ 夜间渔灯；码头船只轻轻碰撞晃动。
3. **飞鸟**：3–5 只程序化海鸥绕岛盘旋（不同半径/高度/相位），翅膀拍打 + 滑翔切换，偶尔落在灯塔/桥塔；黄昏归巢。

**其余：** 椰树摆动（相位错开）、云漂移、海浪、灯塔光束旋转、招牌/旗帜轻摆、雨滴落地涟漪。

### 4.5 天气 → 场景映射

| 数据 | 表现 |
| --- | --- |
| condition.code 1xx | 晴/少云：强定向光、清晰阴影 |
| 2xx/3xx | 云/阴：云量增加、柔光、去饱和 |
| 3xx（300–318, 399） | 雨：粒子雨（数量/长度/速度按 precipitation.intensity）、雨丝随风倾斜、地面积水反光、雨雾 |
| 302/303/304 | 雷雨：雨 + 随机闪电（全城照亮 80ms）+ 可选雷声 |
| 4xx | 雪（海口罕见，保留能力） |
| 5xx（500–515） | 雾/霾：距离雾、远景对比降低、桥塔半隐 |
| wind.speed/direction | 椰树摆幅、雨丝倾角、海浪、云速 |
| cloudCover | 云层密度/遮挡 |
| visibility | 雾浓度 |
| astro.sunrise/sunset | 昼夜光照与太阳位置 |
| AQI | 远景通透度 / HUD 色带 |
| alerts | 顶部预警条 + 场景紧张感 |

### 4.6 UI / 交互

- 顶栏：`海口 · 实况 26.9°C 晴`、AQI、更新时间、数据来源“和风天气 QWeather”、声音开关。
- 右侧天气卡：温度/体感/湿度/风/降水/能见度/日出日落；预警优先展示。
- 底部时间轴：`24 小时` / `7 天` 切换 + 滑块 + 播放按钮；拖动时场景光照/云/雨插值，HUD 跟随。
- 地标按钮（7 个）：点击镜头平滑推近 + 地标卡（该地标视角的天气/一句小知识）+ 返回全景。
- 左上：标题“海口 · 气象微缩城市” + 一行说明。
- 右下：`演示天气` 开关（晴→多云→雨→雷雨→雾循环，标注“演示”）、`昼夜` 切换。
- 首屏加载动画（进度/文案），失败提示 + 重试。
- 移动端：面板折叠为底部抽屉，触摸旋转/缩放。

### 4.7 音频（默认开）

- WebAudio 程序化合成，无外部文件：
  - 海浪：滤波噪声 + 缓慢 LFO；
  - 雨：带通噪声，强度随降水；
  - 风：低频噪声，随风速；
  - 鸟鸣：短促 FM 啁啾，随机间隔；
  - 城市底噪：极轻的低频 hum；
  - 雷声：噪声爆发 + 低通（与闪电同步，延迟 0.5–2s）。
- 首次 pointerdown/keydown 解锁 AudioContext；默认开关为 ON；HUD 有音量/静音按钮；页面失焦自动压低。

### 4.8 性能

- 桌面 60fps、移动 30fps；DPR min(devicePixelRatio,2)；雨粒子桌面 ≤9000、移动 ≤3000。
- 首屏 ≤ 3s（本地）；GLB ≤ 8MB。
- 控制台无报错；无 CORS 报错（全部走本地代理）。
